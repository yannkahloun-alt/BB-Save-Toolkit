## Notes

- The parser tests use synthetic binary buffers for deterministic unit coverage, including a complete synthetic company-brother record through `parse_roster()`.
- Reference regeneration remains an integration concern exactly as specified by the source contract; loading/fallback/error behavior is unit tested.
- Release cleanliness is a property of the ZIP, not of a live pytest working directory (which may create `__pycache__`). It is therefore enforced by `tools/verify_release_zip.py`; the verifier itself is covered by pytest.
